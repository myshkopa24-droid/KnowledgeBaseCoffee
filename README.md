# KnowledgeBaseCoffee

Репозиторий с кодом базы знаний из Notion для курсового проекта на тематику кофе

🔗 **База знаний в Notion:** [Открыть базу знаний в Notion](https://app.notion.com/p/3d231822858680a8bdd2d6347035387a?v=3d231822858680fb841c000c80401731&source=copy_link)

---

## Аннотация курсовой работы

- **Объект исследования:** проектирование базы знаний предметной области кофе.
- **Предмет исследования:** модели, методы и программные инструменты для создания структурированной базы знаний.
- **Цель работы:** разработка рабочего прототипа базы знаний по тематике кофе.
- **Методы исследования:** системный и сравнительный анализ, информационное и реляционно-объектное моделирование, абстрагирование, тестирование сценариев автоматизированного сбора и нормализации данных.
- **Исследования и разработки:** анализ моделей представления знаний и существующих платформ для ведения баз знаний; проектирование архитектуры из восьми взаимосвязанных таблиц в среде Notion; разработка и интеграция через Notion API двух еженедельных сценариев автоматического парсинга и загрузки данных (карточек кофейных лотов и рецептов) на базе платформы n8n.
- **Область возможного практического применения:** информационные системы управления знаниями, образование, автоматизация сбора и систематизации справочных данных, кофейная индустрия и специализированные информационно-справочные сервисы, а также последующая разработка экспертных систем.

---

## Архитектура базы знаний (8 взаимосвязанных таблиц)

В базе знаний реализованы реляционные связи (`Relation`), агрегации (`Rollup`) и вычисляемые формулы (включая определение страны как через связанный регион, так и напрямую для смесей или лотов без региона):

1. **Лоты кофе** — сорта/лоты с основными характеристиками и связями со справочниками.
2. **Регионы** — регионы произрастания, привязанные к странам.
3. **Страны** — справочник стран происхождения.
4. **Способы обработки** — методы обработки зерна.
5. **Способы приготовления** — методы заваривания и рецепты.
6. **Вкусовые ноты** — дескрипторы вкуса и аромата.
7. **Журнал дегустаций** — записи дегустаций, связанные с лотами и способами приготовления.
8. **Медиатека / Источники** — статьи, материалы и внешние ссылки.

## Структура репозитория

- `export_notion_kb.py` — скрипт на Python для выгрузки таблиц через Notion API, сопоставления связей (`relation`, `rollup`) и сохранения данных в JSON и Markdown.
- `data/` — полный граф базы знаний в формате JSON (`knowledge_base.json`) с восстановленными связями.
- `docs/` — страницы и карточки сущностей в формате Markdown с рабочими перекрёстными ссылками.
- `.github/workflows/export.yml` — автоматизированный запуск выгрузки через GitHub Actions.
- `requirements.txt` — список необходимых библиотек Python.
- `.env.example` — шаблон переменных окружения без секретных ключей.
- `.gitignore` — правила исключения локальных файлов и токенов.

---

## Обновление выгрузки

Экспорт данных запускается через вкладку **Actions** (`Export Notion Knowledge Base` → **Run workflow**). Токен интеграции Notion и идентификаторы баз данных хранятся в закрытых секретах репозитория (**Settings → Secrets and variables → Actions**).
