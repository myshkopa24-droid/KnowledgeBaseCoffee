# Эфиопия Гуджи; Колд-брю с апельсином (Френч-пресс)

## Свойства и связи

- **Лоты кофе:** [Эфиопия Гуджи (Ethiopia Guji)](../coffee_lots/эфиопия-гуджи-ethiopia-guji_41a31822.md)
