# Сул-ди-Минас (Sul de Minas)

## Свойства и связи

- **Минимальная высота над уровнем моря:** 700
- **🍒 Вкусы / Дескрипторы:** [Какао](../flavor_notes/какао_41931822.md), [Шоколад](../flavor_notes/шоколад_41931822.md), [Орехи](../flavor_notes/орехи_41931822.md)
- **Страна:** [Бразилия (Brazil)](../countries/бразилия-brazil_3db31822.md)
- **Максимальная высота над уровнем моря (1):** 1250
- **Характерный профиль вкуса:** Классическая бразильская сладость, ноты орехов, шоколада, какао и мягкая кремовость в чашке.
