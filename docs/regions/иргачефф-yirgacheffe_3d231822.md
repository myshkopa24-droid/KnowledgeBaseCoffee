# Иргачефф (Yirgacheffe)

## Свойства и связи

- **Минимальная высота над уровнем моря:** 1700
- **🍒 Вкусы / Дескрипторы:** [Цветы](../flavor_notes/цветы_41a31822.md), [Лимон](../flavor_notes/лимон_3db31822.md), [Персик](../flavor_notes/персик_3db31822.md)
- **Страна:** [Эфиопия (Ethiopia)](../countries/эфиопия-ethiopia_3db31822.md)
- **🌐 Медиатека / Источники:** [Эфиопия Иргачефф](../media/эфиопия-иргачефф_41a31822.md)
- **Максимальная высота над уровнем моря (1):** 2200
- **Характерный профиль вкуса:** Деликатный цветочный профиль (жасмин, белые цветы), ноты бергамота, лимона и персика, лёгкое шелковистое тело и чистая чашка.
