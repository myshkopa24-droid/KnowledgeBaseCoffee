# Шапада Диамантина (Chapada Diamantina)

## Свойства и связи

- **Минимальная высота над уровнем моря:** 1000
- **🍒 Вкусы / Дескрипторы:** [Орехи](../flavor_notes/орехи_41931822.md), [Шоколад](../flavor_notes/шоколад_41931822.md)
- **Страна:** [Бразилия (Brazil)](../countries/бразилия-brazil_3db31822.md)
- **Максимальная высота над уровнем моря (1):** 1400
- **Характерный профиль вкуса:** Высокогорный для Бразилии профиль: больше сладости, орехово-шоколадные ноты и более заметная, но мягкая кислинка.
