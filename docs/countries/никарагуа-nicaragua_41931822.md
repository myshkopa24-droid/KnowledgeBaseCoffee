# Никарагуа (Nicaragua)

## Свойства и связи

- **Описание:** Отличается мягкой кислотностью, хорошей сладостью и оттенками орехов, шоколада, цитрусов и косточковых фруктов с округлым телом.
- **🍒 Вкусы / Дескрипторы:** [Орехи](../flavor_notes/орехи_41931822.md), [Шоколад](../flavor_notes/шоколад_41931822.md), [Фрукты](../flavor_notes/фрукты_41e31822.md), [Цитрусы](../flavor_notes/цитрусы_41931822.md)
- **Континент:** Центральная Америка
