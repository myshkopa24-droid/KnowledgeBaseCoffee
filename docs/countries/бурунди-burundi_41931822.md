# Бурунди (Burundi)

## Свойства и связи

- **Описание:** По профилю близка к руандийской: сочная ягодно-цитрусовая кислотность, цветочные нюансы, сладкое тело и чистое послевкусие.
- **🍒 Вкусы / Дескрипторы:** [Ягоды](../flavor_notes/ягоды_41931822.md), [Цитрусы](../flavor_notes/цитрусы_41931822.md), [Цветы](../flavor_notes/цветы_41a31822.md)
- **Континент:** Африка
