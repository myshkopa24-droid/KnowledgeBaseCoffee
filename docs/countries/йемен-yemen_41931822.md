# Йемен (Yemen)

## Свойства и связи

- **Описание:** Исторический регион выращивания кофе с традиционной сухой обработкой; даёт сложные, пряные, сухофруктовые и винно-шоколадные профили.
- **🍒 Вкусы / Дескрипторы:** [Специи](../flavor_notes/специи_41931822.md), [Сухофрукты](../flavor_notes/сухофрукты_41a31822.md), [Шоколад](../flavor_notes/шоколад_41931822.md), [Вино](../flavor_notes/вино_41e31822.md)
- **Континент:** Азия
