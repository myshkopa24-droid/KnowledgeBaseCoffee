# Гватемала (Guatemala)

## Свойства и связи

- **Описание:** Вулканические почвы и горный рельеф дают чашки с выраженной сладостью, нотами шоколада, карамели, яблок и пряностей при аккуратной, чистой кислотности.
- **🍒 Вкусы / Дескрипторы:** [Шоколад](../flavor_notes/шоколад_41931822.md), [Карамель](../flavor_notes/карамель_3db31822.md), [Яблоки](../flavor_notes/яблоки_41e31822.md), [Специи](../flavor_notes/специи_41931822.md)
- **Континент:** Центральная Америка
- **🌐 Медиатека / Источники:** [Christmas Drip 2027](../media/christmas-drip-2027_41a31822.md), [Christmas  Blend 2027](../media/christmas-blend-2027_41a31822.md), [Брауни](../media/брауни_41a31822.md)
