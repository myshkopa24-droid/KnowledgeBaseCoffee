# Эфиопия (Ethiopia)

## Свойства и связи

- **Описание:** Родина арабики с огромным генетическим разнообразием; мытые лоты дают цветочные и цитрусовые профили (жасмин, бергамот), натуральные — яркие ягодные и десертные ноты.
- **🍒 Вкусы / Дескрипторы:** [Цветы](../flavor_notes/цветы_41a31822.md), [Цитрусы](../flavor_notes/цитрусы_41931822.md), [Ягоды](../flavor_notes/ягоды_41931822.md)
- **Континент:** Африка
- **🌐 Медиатека / Источники:** [Бэрри](../media/бэрри_41a31822.md)
