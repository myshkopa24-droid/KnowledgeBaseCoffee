# Бразилия (Brazil)

- **Описание:** Крупнейший производитель с преимущественно невысокими плантациями; чашки обычно плотные, низкокислотные, с профилем жареных орехов, шоколада, какао и нуги — популярная база для эспрессо и смесей.
