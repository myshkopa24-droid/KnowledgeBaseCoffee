# Вьетнам (Vietnam)

## Свойства и связи

- **Описание:** Крупный производитель робусты (а также части арабики); характерны высокая плотность, выраженная горечь, ноты тёмного какао, древесины и орехов, повышенное содержание кофеина.
- **🍒 Вкусы / Дескрипторы:** [Какао](../flavor_notes/какао_41931822.md), [Древесина](../flavor_notes/древесина_41e31822.md), [Орехи](../flavor_notes/орехи_41931822.md)
- **Континент:** Азия
