# Сухая (Natural)

## Свойства и связи

- **🌐 Медиатека / Источники:** [Бразилия Серрадо](../media/бразилия-серрадо_41a31822.md), [Эфиопия Иргачефф](../media/эфиопия-иргачефф_41a31822.md), [Бразилия Игуасу](../media/бразилия-игуасу_41a31822.md)
- **Вкусовой профиль:** Яркий вкус, Сладкий вкус, Умеренная кислотность, Фруктовые ноты, Ягодные ноты, Плотное тело.
- **Описание:** Сушка цельной ягоды вместе с кожицей и мякотью без предварительной обработки.
