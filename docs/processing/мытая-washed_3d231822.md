# Мытая (Washed)

## Свойства и связи

- **🌐 Медиатека / Источники:** [Колумбия Богота](../media/колумбия-богота_41a31822.md)
- **Вкусовой профиль:** Чистый вкус, Высокая кислотность, Цветочные ноты, Цитрусовые ноты, Лёгкое тело., Среднее тело
- **Описание:** Удаление кожицы, мякоти и клейковины (ферментация водой) перед сушкой. Зерно сушится в пачменте.
