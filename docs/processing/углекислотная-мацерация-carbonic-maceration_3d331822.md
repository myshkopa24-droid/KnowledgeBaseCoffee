# Углекислотная мацерация (Carbonic Maceration)

## Свойства и связи

- **Вкусовой профиль:** Сверхъяркий вкус, Сочные ягоды, Высокая кислотность, Алкогольные ноты, Плотное тело.
- **Описание:** Метод из виноделия: цельные ягоды помещают в резервуар и накачивают туда углекислый газ, вытесняя кислород.
